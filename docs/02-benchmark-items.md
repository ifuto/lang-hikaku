# ベンチマーク項目一覧（50項目）

> 50項目を9カテゴリに分類。各項目は「同じアルゴリズム・同じ規模」を全言語で実装し、速度を比べる。
> 項目の定義データは `benchmarks/items.json` にも同じ内容で格納されている。

## カテゴリ構成

| カテゴリ | 項目数 | 主に測れるもの |
|---|---|---|
| A. 整数演算 | 8 | ループ・関数呼び出し・剰余・除算の速度 |
| B. 浮動小数点 | 10 | 科学計算の速度 |
| C. 文字列処理 | 7 | 文字列・正規表現・ハッシュの速度 |
| D. データ構造 | 8 | 配列・ハッシュ・木・キュー操作の速度 |
| E. 再帰・アルゴリズム | 6 | 再帰・メモリ確保・探索の速度 |
| F. 多倍長整数 | 3 | 大きな数(10進1000桁以上)の演算速度 |
| G. ファイル・I/O | 4 | 読み書き・パースの速度 |
| H. 並行処理 | 2 | スレッドの生成・通信の速度 |
| I. その他 | 2 | 乱数生成・出力生成 |
| **合計** | **50** | |

## 設計上の注意

- **規模の決め方**: 最速のCで約0.2〜5秒、最遅のインタプリタ言語でも数分以内に終わる規模に調整してある。規模は自由に変えられるので、「規模を2倍にしたら時間はどう伸びるか」という**計算量オーダーの観察**にも使える（追加研究テーマ）。
- **正しさの検証**: 各言語のプログラムは必ず「答え（チェックサム）」を1行出力し、全言語の出力が一致することを自動検証する。出力が違うプログラムは「結果不一致」として集計から外す。
- **最適化で消えない工夫**: 空ループや不要な計算はコンパイラが消してしまうため、必ず結果を合計に足して出力する。
